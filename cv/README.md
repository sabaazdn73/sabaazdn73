# My CV

Edit **`CV.md`** only. Everything else is made from it.

1. Change the text in `CV.md`.
2. Run `python3 build.py` (first time: `pip3 install markdown`). This rewrites `index.html`.
3. Open `index.html` in Chrome, then File > Print > Save as PDF, and save it as `Saba_Azadegan_CV.pdf` here.
4. Commit and push.

Which file to use where:

- **Job application forms that ask you to upload:** `Saba_Azadegan_CV.pdf`. It has real, selectable text, one column and plain headings, so recruiting software reads it correctly.
- **Forms with a text box:** copy from `CV.md`. It is plain text.
- **A link to share:** `index.html` (it can be served with GitHub Pages).
