AI evaluation

Expert eval harness

2026 · github.com/sabaazdn73/expert-eval-harness · Python, Claude and Gemini APIs, GitHub Actions

A single answer says little about how reliably a model handles expert work. The open-source harness runs each task several times per model and scores every answer item by item against the expert key, with pass@k, pass^k, confidence intervals and difficulty and quality gates. On the hackathon tasks two LLM judges from different model families agreed on 96% of items; every disagreement goes to a human expert.

RC Code Town

2026 · tnega.app/town · three.js

Reviewers need to see where in a building an AI model tends to go wrong. RC Code Town shows six types of US concrete structures in 3D at true scale, with geometry from FEMA, FHWA and code sources; clicking a part shows the governing provisions and the errors AI models tend to make there (84 failure cards, 25 review scenarios). Some of my evaluation tasks are set on these buildings; an AI reviewer for structural drawings is in development on the same site.

Research

Structural reliability of reclaimed steel

Self-directed · Nov 2026 · github.com/sabaazdn73/reclaimed-steel-reliability · Python

Steel from dismantled structures can be reused, but its properties are more uncertain. I implemented FORM in Python, checked it with importance sampling and Monte Carlo, and calibrated the partial factor giving reclaimed steel the same reliability as modern steel, for two failure modes and three steel scenarios.

Pipeline damage detection with ML

Self-directed · Apr 2026 · github.com/sabaazdn73/Pipeline-Damage-ML · NumPy, scikit-learn

Surrogate models can stand in for repeated finite element runs. I trained them on simplified FEM simulations of wall-thickness loss in a pipe; The Gaussian process, compared with linear regression and random forest, reached R² = 0.997 with uncertainty bounds.
